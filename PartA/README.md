# Part A - Hack Computer HDL

Files: `CPU.hdl`, `Memory.hdl`, `Computer.hdl`.

Run the official `CPU.tst` against `CPU.hdl`, `Memory.tst` against `Memory.hdl`, and `ComputerAdd.tst`, `ComputerMax.tst`, `ComputerRect.tst` against `Computer.hdl` in the Nand2Tetris Hardware Simulator. Save the successful comparison screenshots in `../evidence/`.

The implementation intentionally uses built-in `ARegister`, `DRegister`, `ALU`, `PC`, `RAM16K`, `Screen`, `Keyboard` and `ROM32K` chips, plus standard logic chips. The assignment permits using built-in versions of earlier lab chips when needed; this dependency is disclosed in the main README and student report.
